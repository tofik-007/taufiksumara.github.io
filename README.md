# Taufik Sumara — Personal Portfolio Website

> A modern, responsive cybersecurity portfolio built with pure HTML, CSS, and JavaScript.

🌐 **Live Site:** [taufiksumara.github.io](https://taufiksumara.github.io)

---

## 👤 About

This is the personal portfolio website of **Taufik Sumara**, a Master of Information Technology Security (MITS) candidate at Ontario Tech University, graduating December 2025. The site showcases his professional experience, cybersecurity projects, technical skills, education, and contact information — designed to make a strong impression on recruiters and hiring managers in the cybersecurity industry.

---

## ✨ Features

- **Custom animated cursor** with trailing ring effect
- **Particle network background** rendered on HTML5 Canvas
- **Scroll-triggered animations** using Intersection Observer API
- **Glassmorphism cards** with teal glow on hover
- **Hero grid parallax** effect tied to mouse movement
- **Spinning conic gradient** ring around the avatar
- **Fully responsive** layout for mobile, tablet, and desktop
- **Smooth scroll** navigation between sections
- **Zero dependencies** — no frameworks or libraries

## 🚀 Getting Started

No build tools or installations required.

### Run Locally

```bash
# Clone the repository
git clone https://github.com/taufiksumara/taufiksumara.github.io.git

# Navigate into the folder
cd taufiksumara.github.io

# Open in browser
open index.html
```

Or simply drag and drop `index.html` into any browser.

---

## 🌍 Deployment

This site is hosted on **GitHub Pages** as a static site.

To deploy your own version:

1. Fork or clone this repository
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Your site will be live at `https://<your-username>.github.io`

Alternatively, deploy instantly on [Netlify](https://netlify.com) or [Vercel](https://vercel.com) via drag and drop.
